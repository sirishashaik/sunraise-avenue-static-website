# Sunraise Avenue – Real Estate Website

## Live Demo
[Visit Sunraise Avenue](https://sirishashaik.github.io/sunraise-avenue-static-website/)

## About the Project

Sunraise Avenue is a static real estate website developed to showcase modern flats and apartment options. It provides visitors with an easy way to explore different apartment configurations, including 2 BHK, 3 BHK, and 4 BHK flats.

The website focuses on a clean design, simple navigation, and a user-friendly browsing experience.

## Features

- Attractive homepage design.
- Flats listing page.
- Separate pages for 2 BHK, 3 BHK, and 4 BHK apartments.
- Easy navigation between different pages.
- Apartment details and booking interface.
- Responsive styling for different screen sizes.

**Note:** The booking interface is currently for demonstration purposes. Actual booking submission and data storage have not been implemented.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 4.5.2
